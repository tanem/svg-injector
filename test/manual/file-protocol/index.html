file:// transport check

Open this file directly from disk, not through a server. What the transport reports for file:// is engine-specific, so the table records the observed status and Content-Type beside each verdict: those two values are what the .svg extension bypass and isLocal() exist to handle, and they cannot be inferred from one browser.

Chromium and WebKit block file:// → file:// XHR at default settings. In Chrome, run with --allow-file-access-from-files; in Safari, enable Develop → Developer Settings → Disable Local File Restrictions. Without that, every case reports the local-security error and only the no-hang assertions mean anything.
