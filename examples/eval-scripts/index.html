Eval Scripts

Two SVGs, each carrying a <script> that increments a counter on this page. Both are injected again every time the button is pressed. The 'once' counter stops at 1 and the 'always' counter keeps climbing, which is the whole difference between the two settings. The default, 'never', would leave both at 0.

evalScripts: 'once'

The script sits at the root of the file, next to the circle.

Script runs: 0

evalScripts: 'always'

The script sits inside a <g>, alongside the square it is grouped with.

Script runs: 0

Injections per SVG: 0 · <script> elements left in the injected markup: 0

The scripts are removed from the markup whichever setting is used, so nothing above ever reaches the DOM as a <script> element. They run through new Function instead, before beforeEach is called and before the SVG is put on the page. That ordering is why the Security section says sanitising in beforeEach does not stop them.
