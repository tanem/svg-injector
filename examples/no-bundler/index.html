No Bundler

Nothing on this page is bundled. It is served as a static file and loads the library with a <script type="module"> tag, from a copy of dist/svg-injector.mjs sitting next to index.html: 

<script type="module">
  import { SVGInjector } from './svg-injector.mjs'

  SVGInjector(document.getElementById('inject-me'))
</script>

Injecting…

There is no window.SVGInjector. v11 defined one through its UMD builds, which 12.0.0 removed; an ES module exports its bindings to whatever imports it and puts nothing on the global object.
