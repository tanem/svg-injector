SVG Data URL Injection

These icons use data:image/svg+xml URLs in their data-src attributes, as a bundler like Vite would produce. The SVG content is parsed directly from the data URL without making a network request.

URL-encoded with a charset parameter

The parameter list is case-insensitive, so charset=UTF-8 and charset=utf8 are treated the same as charset=utf-8.

Base64-encoded with multi-byte text

Base64 data is decoded as UTF-8, so accented characters and characters outside the Basic Multilingual Plane render as authored. This one should read café 🎉.
